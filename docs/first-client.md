# Generate and compile your first client

Start with one `Greeting` payload and the built-in `ServiceResponse<T>` envelope. Both builds use
released **1.3.0** artifacts, official OpenAPI Generator **7.27.0**, and the same Boot 4.1.2 / Jackson 3
RestClient dependency profile. These are example inputs, not support minima or build-tool requirements.

You need **JDK 21** and either **Maven 3.9.x** or **Gradle 9.x** (verified with 9.9.1).
No platform checkout build, local artifact install, producer process, BYOE or BYOC setup is needed.

## Get the files

Download or clone the repository and copy
[`examples/first-client`](https://github.com/blueprint-platform/openapi-generics/tree/main/examples/first-client)
to an empty directory. Keep this structure; choose only one build tool:

```text
first-client/
  spec.yaml
  maven/pom.xml
  maven/src/main/java/example/UseClient.java
  gradle/settings.gradle.kts
  gradle/build.gradle.kts
  gradle/src/main/java/example/UseClient.java
```

The runnable files are the source of this tutorial and are built in CI against public repositories.
They stay pinned to released platform dependencies while the repository itself develops 1.3.1-SNAPSHOT.

## Inspect the input

[`spec.yaml`](https://github.com/blueprint-platform/openapi-generics/blob/main/examples/first-client/spec.yaml)
contains one operation, one ordinary DTO and a concrete envelope schema. Its reconstruction metadata is:

```yaml
x-api-wrapper: true
x-api-wrapper-type: io.github.blueprintplatform.openapi.generics.contract.envelope.ServiceResponse
x-api-wrapper-datatype: Greeting
```

A real [Spring MVC producer](adoption/server-side-adoption.md) emits this metadata from Java contracts.
Here it is supplied directly so the first build needs no running server. The API's `info.version: 1.0`
is independent of the platform artifact version.

## Maven

From `first-client/`:

```bash
mvn -f maven/pom.xml clean verify
```

The [complete POM](https://github.com/blueprint-platform/openapi-generics/blob/main/examples/first-client/maven/pom.xml)
inherits the public codegen parent, declares the generator execution and includes shared contract and
RestClient dependencies. Maven Central is Maven's default repository. If your organization requires a
corporate parent, read the [parent decision](adoption/client-side-adoption.md#maven) before adapting it.

Expected wrapper:
`maven/target/generated-sources/openapi/src/gen/java/example/generated/model/ServiceResponseGreeting.java`.

## Gradle

From `first-client/`, with Gradle 9.x installed:

```bash
gradle -p gradle clean build
```

The [settings](https://github.com/blueprint-platform/openapi-generics/blob/main/examples/first-client/gradle/settings.gradle.kts)
resolve plugin markers through the public Plugin Portal. Content filters keep the platform
implementation and dependency graph on Maven Central; the official OAG Gradle implementation is
resolved from the Portal normally. This is channel selection, not a dependency/version override.
The [build](https://github.com/blueprint-platform/openapi-generics/blob/main/examples/first-client/gradle/build.gradle.kts)
applies both plugins and lets the platform register generated sources automatically.

Expected wrapper:
`gradle/build/generated/openapi/src/gen/java/example/generated/model/ServiceResponseGreeting.java`.

For repeatable builds in your own project, add a wrapper for your selected supported Gradle version.
The example does not use the repository's development composite build or `mavenLocal()`.

## Verify the result

Both builds must succeed and generate:

```java
public class ServiceResponseGreeting extends ServiceResponse<Greeting> {}
```

The ordinary `Greeting` DTO and API/invoker are generated by upstream JavaClientCodegen. The envelope
comes from the shared contract artifact. The accompanying `UseClient` source calls the generated API
and returns `ServiceResponse<Greeting>`; compilation verifies that assignment. Nothing calls a live
HTTP endpoint in this example. Use the [canonical application](https://github.com/blueprint-platform/openapi-generics/blob/main/samples/gradle/customer-service/README.md)
for direct/paged HTTP deserialization evidence.
