# openapi-generics-contract

Use shared Java success-envelope, pagination and error-extension types in producers and client libraries.
This module owns the **built-in** contracts. Application-owned BYOE (Bring Your Own Envelope) envelopes and BYOC (Bring Your Own Contract) DTOs retain
their own authority; this is not the owner of every API model.

```java
var page = Page.of(customers, 0, 10, totalElements);
ServiceResponse<Page<CustomerDto>> response = ServiceResponse.of(page);
```

The library targets Java 17+ and has no Spring, Springdoc, Jackson or OpenAPI-annotation dependency.
It can be used without projection or client generation.

## Add the dependency

```xml
<dependency>
  <groupId>io.github.blueprint-platform</groupId>
  <artifactId>openapi-generics-contract</artifactId>
  <version>1.3.0</version>
</dependency>
```

Keep producer and client contract versions aligned. A client library should expose shared types as
part of its API dependencies and make them available at runtime; a `provided` scope requires the
consuming application to supply them.

## Types and behavior

| Type | Use |
| --- | --- |
| `envelope.ServiceResponse<T>` | Mutable `data` and `meta`; no-arg constructor for binding; `of(data)` / `of(data, meta)` factories |
| `envelope.Meta` | Record containing server time and sorting; `Meta.now()` creates current-time metadata |
| `paging.Page<T>` | Record containing `List<T> content`, page/size/totals and navigation flags; `Page.of(...)` derives pagination values |
| `paging.Sort`, `SortDirection` | Framework-independent sorting description |
| `error.ErrorItem`, `ProblemExtensions` | Structured error extension values, usable in RFC 9457 problem responses |

`ServiceResponse` defaults missing metadata to `Meta.now()`. The library is not an HTTP exception
handler, validator or pagination query engine. Platform `Page<T>` is distinct from Spring Data `Page<T>`.
Consult the Java types/Javadoc for factory and accessor details; framework integration is deliberately
kept in other modules.

## How generation uses these types

A projected `ServiceResponse<Page<CustomerDto>>` becomes a generated subclass:

```java
public class ServiceResponsePageCustomerDto
    extends ServiceResponse<Page<CustomerDto>> {}
```

The subclass binds concrete parameters for transport/deserialization. It does not redefine the shared
contracts. Generated API/invoker/wrapper classes belong behind a client adapter; application methods
can continue returning `ServiceResponse<Page<CustomerDto>>`.

Envelope ownership can instead stay with an application's BYOE class. DTO reuse through BYOC is
optional: ordinary DTOs may still be generated by upstream OpenAPI Generator (OAG). Neither choice adds framework
responsibilities to this module.
